# 个人拼多多订单 MCP 方案

基于纯前端底层静默请求技术，全自动提取拼多多个人订单的物流单号。

> ⚠️ **免责与避坑声明**：因拼多多前端混淆机制，提取结果**无法保证 100% 准确**，可能混入商品测试 ID、虚假国际单号。请结合官方 App 人工核对。

## 功能特性
- **免手动点击**：自动接管浏览器滑动，触发订单加载。
- **静默详情页提取**：后台静默请求，绕过前端重定向。
- **MCP 直连**：提供 HTTP 接口，随时查询。

## 快速开始
1. 一键安装依赖：
   chmod +x install.sh
   ./install.sh

2. 查看可用命令：
   PDD-help

3. 启动服务：
   PDD-run

4. 环境出问题了？一键修复：
   PDD-doctor

5. 在 MCP 客户端中配置接口：http://127.0.0.1:8000/get_orders
